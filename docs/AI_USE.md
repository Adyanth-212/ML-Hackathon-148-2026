# AI-use disclosure

AI assistance (Anthropic Claude) was used under the team's direction for parts of the code (data foundation, features and
the shared evaluation harness, Bayesian optimisation, HMM integration, evaluator scoring, UI and API wiring, Folium
maps) and for drafting the technical report. The organisers confirmed that AI-assisted report text is allowed when
disclosed.

All experiments were run by the team with the scripts in this repository, every number and figure in the report is read
from `experiments/results/` and `experiments/figures/`, and every member has reviewed the code and the report.
